# NodeMail Docs

NodeMail 是面向 NodeLoc 黄金会员及以上用户开放的邮箱服务。

- 服务入口：<https://to9.us/login>
- 在线文档：<https://aoliao-aoliao.github.io/nodemail-docs/>
- 登录方式：NodeLoc 第三方登录

这个仓库用于发布 NodeMail 的公开说明页，内容主要包括登录、创建邮箱、收发邮件、个人设置、临时发信申请和反馈工单等用户可见功能。

## 本地预览

```bash
npm install
npm run docs:dev
```

## 构建

```bash
npm run docs:build
```
