管理员指南

  • 完整 Web 邮箱

    多邮箱统一收件箱、会话阅读、富文本写信、草稿、附件、搜索、文件夹、标签、规则和联系人。

  • 企业邮局

    创建组织、接入自有域名、邀请成员、分配角色与邮箱，并按组织配置品牌和发信通道。

  • 标准邮件协议

    通过应用专用密码连接 IMAPS、POP3S 和 SMTP Submission，继续使用常见桌面与移动客户端。

  • 安全与可达性

    SPF、DKIM、DMARC 状态提示，rspamd 反垃圾与隔离区，登录限流、TOTP 两步验证和审计日志。

  • 套餐与计费

    个人 Pro、企业套餐、订单、钱包、在线支付、兑换码以及取消和恢复订阅流程。

  • 通知与开放能力

    站内通知、浏览器通知、Telegram 通知、系统公告、个人 API 密钥和 OpenAPI 参考。

系统边界 ​

草丛 Mail 是正常通信和企业邮箱平台，不是群发营销工具。系统会按用户、域名、套餐和管理员策略限制发信权限与频率，并可能拦截高风险收件人或异常内容。

邮件在传输过程中使用 TLS，并支持 DKIM 签名、SPF/DMARC 检查和反垃圾处理。平台没有宣称端到端加密或服务端不可读，请不要把普通邮箱当作端到端加密通信工具。
