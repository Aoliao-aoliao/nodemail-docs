设置与通知 ​

账号资料 ​

“管理 → 账号设置”显示用户名、绑定邮箱、OAuth 绑定、时区、用户等级和当前配额。时区会影响邮件时间、审计记录和自动回复时间窗口。

本地账号可以修改密码；OAuth 账号可绑定本地邮箱和密码作为备用登录方式。解绑 OAuth 前应确保仍有其他可用登录方式。

邮件偏好 ​

邮件设置包括：

  • 标签与文件夹管理。
  • 联系人和联系人访问控制。
  • 全局签名及按发件邮箱选择的签名。
  • 白名单与收信规则。
  • 默认图床地址、个人图床 API Key 和上传策略。
  • 全局自动回复及邮箱级覆盖。

白名单会影响垃圾邮件判断，只添加可信地址或域名。图床密钥属于敏感凭据，不要粘贴到工单或公开页面。

通知中心 ​

站内通知同时显示系统公告和账号相关事件，并提供未读数量与全部已读操作。管理员可按受众发布公告，个人事件可能来自订单、订阅、共享或其他业务流程。

浏览器通知需要浏览器授权。若点击测试没有弹窗，应检查浏览器站点权限、系统勿扰模式以及页面是否通过 HTTPS 打开。

Telegram 通知 ​

管理员配置机器人后，用户可从通知设置发起 Telegram 绑定。绑定采用 Telegram 官方网页登录授权；成功后可发送测试通知，也可随时解绑。

不要把普通 /start 当作账号绑定流程，也不要把机器人 Token 发给任何人。

登录与审计记录 ​

安全记录显示登录时间、来源和关键账号操作。发现未知登录时应立即修改密码、撤销应用专用密码、强制退出其他会话并联系管理员。

客户端服务器 ​

第三方邮件客户端统一使用：

text
服务器：mail.to9.us
IMAPS：993（SSL/TLS）
POP3S：995（SSL/TLS）
SMTP Submission：587（STARTTLS）
用户名：完整邮箱地址
密码：该邮箱的应用专用密码

推荐 IMAP；POP3 更适合只下载单一收件箱的旧式客户端。不要在未加密连接中提交密码。
