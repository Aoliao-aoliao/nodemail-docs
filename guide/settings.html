本页目录

设置与通知 ​

“管理 → 账号设置”分为账号、安全、外观、通知和邮件偏好等区域。页面只展示当前账号实际可用的操作。

账号资料与身份 ​

账号信息分别显示用户名、找回邮箱、注册来源、NodeLoc 绑定、NodeLoc 真实等级、本站系统配额等级和时区。

  • 普通注册用户显示“普通账号”。后来绑定 NodeLoc 仍保持这一注册来源。
  • NodeLoc 直接登录创建的用户显示“NodeLoc 账号”。
  • 已绑定 NodeLoc 的用户额外显示真实 TL0–TL4；取不到等级时显示“等级待同步”。
  • L0–L4 是本站配额档位，不等于 NodeLoc 会员等级。

时区会作为账号偏好保存，并显示在账号资料和管理员用户列表中。当前网页里的邮件、审计与统计时间，以及自动回复的时间输入，主要仍按浏览器本地时区解析和展示；修改账号时区不会强制改变浏览器时钟。

能量、存储与账号配额 ​

账号页显示能量余额、转入或充值入口、能量流水、已用存储和当前有效配额。邮箱创建、每日发信、应用专用密码和协议频率的限制都以服务端实时计算结果为准。

若管理员设置了“免费账号邮箱创建阈值”，没有有效个人付费套餐的账号达到该邮箱数量后会停止继续创建，即使系统配额仍有余量。阈值为 0 时不应用这层额外限制；付费账号仍受最终邮箱配额约束。

NodeLoc 能量和人民币充值会跳转到管理员启用的支付渠道，支付完成后以钱包流水和余额为准。关闭支付页面或网络中断时先刷新记录，不要重复创建多笔订单。

密码、找回邮箱与两步验证 ​

本地账号可修改密码、绑定或更换找回邮箱、启用 TOTP 两步验证和强制退出其他会话。找回邮箱的新增或更换必须经过邮件验证码，不能只改资料字段。

OAuth 注册账号的密码由原登录平台管理；页面会明确提示来源。普通账号绑定 NodeLoc 前还需要当前密码或 TOTP，避免浏览器会话被他人拿来抢绑身份。

NodeLoc 绑定状态 ​

绑定卡片显示 NodeLoc 账号、NodeLoc ID、真实等级、同步状态和最后同步时间。状态可能为已同步、待同步、同步失败或需要重新授权。重新授权只能使用原绑定身份。

完整说明见 NodeLoc 身份、等级与本站配额。

邮件偏好 ​

用户可配置：

  • 标签与自定义文件夹。
  • 联系人及个人发件人白名单。
  • 全局签名和按发件邮箱选择的签名；每个范围只会有一个默认签名。
  • 白名单与收信规则。
  • 默认图床地址、个人图床 API Key 和上传策略。
  • 全局自动回复与邮箱级覆盖。
  • 远程图片加载策略：始终拦截、仅对白名单加载或始终加载。

个人图床密钥会加密保存，读取页面时不回显明文。白名单会影响垃圾邮件判断，只添加可信且范围最小的地址或域名。

图床不可用时，写信图片会回退为内嵌内容。自动回复使用正常发信配额和能量规则；开启“只回复一次”后，数据库会限制同一邮箱对同一发件人 24 小时内重复回复。邮箱级配置优先于全局配置。

通知中心 ​

通知中心汇总系统公告和账号相关事件，支持未读数量、单条已读与全部已读。管理员可向所有用户、个人用户或指定企业发布公告；邮箱转让、订阅生命周期和命中“通知”动作的收信规则会产生个人通知。

浏览器通知需要 HTTPS、浏览器授权和系统允许。测试没有弹窗时依次检查站点通知权限、系统勿扰模式和浏览器后台限制。

发送预览、免打扰和通知聚合目前会保存为账号偏好，但尚未接入发信确认或通知调度流程。开启这些选项不会自动增加发送前预览，也不会按免打扰时段缓冲或批量投递通知。

“AI 邮件安全分析”当前只保存用户偏好，不会自动把邮件发送给外部 AI。邮件详情中的安全评估来自 SPF、DKIM、DMARC 和本地规则分数。

Telegram 通知 ​

管理员配置全站 Bot Token 后，用户可以发起 Telegram 官方网页登录绑定。绑定请求带一次性状态并有有效期，成功后可发送测试通知或随时解绑。

不要把普通 /start 当作账号绑定，也不要向任何人发送机器人 Token。Telegram 配置只影响通知，不改变草丛 Mail 登录身份。

安全页 ​

安全页集中管理找回邮箱、修改密码、TOTP、当前会话、登录历史和临时发信申请。临时发信申请会显示待审核、通过或拒绝状态；域名策略、能量和发信配额仍会继续检查。

客户端服务器 ​

第三方邮件客户端统一使用：

text
服务器：mail.to9.us
IMAPS：993（SSL/TLS）
POP3S：995（SSL/TLS）
SMTP Submission：587（STARTTLS）
用户名：完整邮箱地址
密码：该邮箱的应用专用密码

推荐 IMAP；POP3 适合只下载单一收件箱的旧式客户端。客户端不得在未加密连接中提交密码。
