安全策略 ​

登录安全 ​

NodeMail 支持：

  • HttpOnly Cookie 会话
  • Access Token 短期有效
  • Refresh Token 自动续期
  • 登录历史
  • 2FA 状态管理

邮箱名前缀保护 ​

系统保留管理类邮箱前缀，防止用户冒充系统身份。

黑名单 ​

全局黑名单可用于限制：

  • IP
  • 发件域名
  • 发件邮箱

发信限制 ​

建议开启：

  • 每日发信上限
  • 新用户更低额度
  • 临时发信审批
  • 附件大小限制
  • 异常用户禁用

工单管理 ​

管理员可以处理、回复、关闭和删除工单。
