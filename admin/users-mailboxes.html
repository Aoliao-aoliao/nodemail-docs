用户与邮箱 ​

用户管理 ​

管理员可以：

  • 启用或禁用用户
  • 调整用户等级
  • 设置邮箱数量上限
  • 设置每日发信上限
  • 重置密码或 2FA
  • 强制用户退出登录

邮箱管理 ​

邮箱可配置：

  • 显示名
  • 收信状态
  • 协议状态
  • 转发地址
  • 归档状态

保留邮箱名前缀 ​

系统会保留常见管理邮箱名：

text
admin
root
postmaster
abuse
security
support
webmaster

普通用户不能注册，管理员可以创建。
