用户与邮箱管理 ​

用户列表与筛选 ​

用户页可按用户名或找回邮箱搜索，按启用状态和管理员角色筛选，并按注册时间、用户名、邮箱或系统配额等级排序。每页可显示 20、50 或 100 条。

列表中的徽章分别表示：

徽章数据含义
普通账号 / NodeLoc 账号 / Google 账号等首次注册来源
青铜、白银、黄金、钻石或王者会员NodeLoc 绑定返回的真实 TL0–TL4
系统配额 L0–L4本站实际使用的配额模板档位
⚡ 数字当前能量余额

每一行都从该账号自己的 oauth_account_bindings.external_level_code 读取 NodeLoc 等级，只有真实值为 TL2 才显示“黄金会员（TL2）”。普通账号绑定 NodeLoc 后仍显示“普通账号”，同时多一枚真实 NodeLoc 等级徽章。若绑定存在但暂时没有可信等级数据，显示“等级待同步”，不会回退到 users.level 或拿系统配额等级猜测。

账号控制 ​

展开用户后可执行：

  • 启用或禁用账号。
  • 授予或撤销管理员权限。
  • 查看注册来源、NodeLoc 实际等级与系统配额等级。
  • 调整 L0–L4 系统配额档位。
  • 设置存储、邮箱数和每日发信的单用户覆盖值。
  • 查看邮箱、存储、今日发信、能量钱包、充值与最近流水。
  • 为本地账号重置密码。
  • 重置 TOTP、强制下线、代入登录或永久删除。

OAuth 注册账号的密码由原提供方管理，后台不会显示本地重置入口。管理员重置密码、重置 2FA 和强制下线都会撤销用户现有令牌。

代入登录时会保留管理员审计身份，并禁止所有凭据变更。结束排障后立即退出代入会话。

配额优先级 ​

排查用户配额时按以下顺序：

  1. 管理员为该用户设置的覆盖值。
  2. 个人 Pro 套餐提供的权益。
  3. 当前系统配额 L0–L4 的模板值。
  4. 全局默认配额。

NodeLoc 的 TL 等级只负责通过后台映射选择系统 L 档位。企业邮箱使用组织订阅配额，不由个人 NodeLoc 等级直接决定。

用户详情里的邮箱数量、存储和“今日发信收件人”只统计该用户的个人邮箱。获分配的企业邮箱不会混入个人数字；企业存储和今日共享发信用量应到对应组织页面查看。

删除用户 ​

禁用账号只停止访问，不删除数据。永久删除前核对邮箱归属、组织所有权和成员关系、共享、转让、订单、订阅、钱包、工单和 API Key。

删除流程由事务和数据库约束保护。必要审计日志会保留，已删除用户的外键引用置空；不要直接在数据库中逐表删除来绕过检查。

邮箱管理 ​

管理员邮箱页显示地址、域名、所属用户、状态、容量和时间。可搜索地址或用户名，点击所属用户可跳到已筛选的用户页。

可调整：

  • 外部转发地址配置；来信本地保存后会按正常发信策略执行转发，并把结果写入邮件流转。个人邮箱计用户额度并可能消耗能量，企业邮箱计组织共享额度。
  • 是否接收邮件。
  • 是否允许 IMAP、POP3 和 SMTP Submission 等协议访问。
  • 归档状态。

邮箱转让、共享、清理和应用专用密码由各自业务流程管理。个人清理与“全部粉碎”接口只接受个人邮箱，不会处理企业邮箱。转让完成后，原所有者不再拥有管理权限；共享当前是只读访问，不授予发信、改设置或删除邮箱权限。

邮件数据访问 ​

管理员排查邮件时遵守最小访问原则。优先使用邮件 ID、时间、投递状态、认证结果和邮件流日志；确有需要时才查看正文或附件。所有下载接口继续执行邮箱所有权、组织管理员或只读共享范围校验。
