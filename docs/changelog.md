# 更新日志

## 2026-09-06 · 安全与一致性修复

- 强制开放注册在启用邮箱验证时填写并验证找回邮箱，增加来源 IP 每小时/每天注册限速。
- 加入 Cloudflare Turnstile 完整配置校验和故障关闭策略；补充后台设置与部署环境变量。
- 密码修改、密码找回、管理员重置密码、重置 2FA 和强制退出会撤销已有令牌；找回邮箱只能通过验证码修改。
- 修复组织邀请可能命中本地同名账号的问题，成员邀请只认已绑定的 NodeLoc 身份。
- 让邮箱共享权限实际覆盖邮件列表、详情、会话、原文和附件，并执行文件夹/标签范围限制及阅读记录。
- 限制个人邮箱只能使用活跃公共域名，补齐组织管理员读取企业邮件和附件的权限。
- 禁止组织上传 SVG Logo，并按实际文件内容验证 PNG、JPEG、WebP 或 GIF，降低存储型脚本攻击风险。
- 修复前后台 8 处接口不一致、分页边界、图床配置优先级和管理设置错误处理。
- 升级并审计 Go、Axios、DOMPurify、Tiptap 等依赖；生产前端和官网构建均无已知依赖漏洞。
- 增加 HSTS、内容安全策略和权限策略；Docker 基础镜像固定摘要，数据库密码不再提供默认值。
- 数据库迁移扩展到 048，加入注册频率设置、共享阅读记录和组织角色/状态约束。

## 2026-09-05 · 草丛 Mail 平台升级

### 产品与界面

- 品牌统一为中文“草丛 Mail”、英文“CaoCong Mail”，恢复原项目闪电标志。
- 新增独立产品官网，邮箱应用迁移到 `/app/`，保留旧地址兼容跳转。
- 完成中英文界面、移动端布局和本地化检查。

### 账号与安全

- 新增可配置的邮箱注册、邮箱验证码、找回密码和绑定邮箱流程。
- OAuth 提供方改为后台可配置，保留 NodeLoc 旧回调地址兼容。
- 增加 TOTP 两步验证、强制退出、管理员重置 2FA 和登录审计。
- 登录接口加强限流；访问令牌和刷新令牌用途分离。

### 邮箱与协作

- 加强邮件搜索、会话、原文查看、批量处理、附件下载和导入导出。
- 增加邮箱排序、应用专用密码、自动回复、共享邀请与活动记录。
- 增加邮箱转让、延迟清理、永久保留和彻底清理流程。
- 修复 IMAP UID 完整性，并优化大邮箱 POP3 列表性能。

### 企业邮局

- 新增组织、所有者/管理员/成员角色、自有域名验证和企业邮箱管理。
- 支持组织品牌、Logo、主色和自定义发信通道。
- 增加企业套餐、订阅生命周期、域名/邮箱/存储配额。

### 发信与安全

- 增加域名发信审批、用户发信申请、直接 MX 与中继通道策略。
- 完善 DKIM 签名、DNS 健康检查、收件人预检、黑名单和抑制名单。
- rspamd 隔离区支持查看、释放、申诉和删除。

### 套餐、支付与通知

- 新增个人 Pro 与企业套餐、订单、支付回调、取消/恢复订阅。
- 新增钱包、人民币充值、交易流水和兑换码。
- 新增站内通知、未读计数、系统公告、浏览器与 Telegram 通知。

### 开发与运维

- 新增个人 API 密钥、作用域控制、开发者页面和 OpenAPI 说明。
- 数据库迁移扩展到 047，并使迁移失败时服务停止启动，避免半迁移运行。
- Docker 构建改为锁定依赖安装，加入官网服务和同域 Nginx 路由。
- 保留原 166 个用户、182 个邮箱和 777 封邮件完成原地升级。
- 更新 `mail.to9.us` 的 IMAP、POP3 与 SMTP TLS 证书并配置自动续期。
