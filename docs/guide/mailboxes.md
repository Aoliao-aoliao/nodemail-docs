# 邮箱管理

## 创建与配额

在“管理 → 邮箱管理”选择域名并输入前缀。系统同时检查地址占用、保留前缀、域名是否允许注册、用户等级和套餐邮箱数量上限。

配额来自多层规则：平台默认值、用户等级、个人订阅、企业订阅以及管理员为用户单独设置的覆盖值。页面“我的套餐”和邮箱存储详情显示当前生效结果。

## 基本资料与排序

每个邮箱可以维护显示名称、转发目标等资料。拖动排序后，新的顺序会用于邮箱选择器；第一个可用邮箱通常是登录后的默认邮箱。

## 转发与自动回复

转发把新邮件发送到指定外部地址。配置错误可能形成循环，因此不要把两个邮箱互相转发。

自动回复支持启用状态、正文、开始与结束时间、回复范围以及邮箱级覆盖。系统会尽量跳过邮件列表、自动邮件和疑似循环，并限制同一发件人的重复回复。

## 应用专用密码

IMAP、POP3 和 SMTP 客户端使用邮箱地址与应用专用密码认证。创建时为密码填写易识别的名称，例如“iPhone”或“Thunderbird”。密码只在创建时完整显示，应立即保存到密码管理器。

怀疑泄露时删除对应应用密码，不必修改网页登录密码。不同设备使用不同密码，便于单独撤销。

## 邮箱共享

共享通过邀请完成。被邀请人可以接受或拒绝；所有者可以授权整个邮箱，也可以只授权指定系统文件夹、自定义文件夹或标签。受邀人可在网页中查看获授权的邮件、会话、原文和附件，但共享本身不授予发信或邮箱管理权。

共享列表会记录实际阅读次数和最近阅读时间。受限共享不会显示整个邮箱的汇总邮件数，避免通过统计值泄露未授权目录的信息。所有者可以调整范围、撤销单个共享或一次撤销全部共享。只向可信账号授权，并定期清理不再需要的访问。

## 邮箱转让

转让会把邮箱所有权交给另一位用户。请求可接受、拒绝或在完成前取消。转让前应确认目标用户、邮箱内容和后续配额，因为所有权变化会影响管理与删除权限。

## 归档与删除

归档邮箱适合暂停使用但保留数据。删除邮箱前先处理转发、共享、客户端密码和重要邮件。企业邮箱还受组织角色和企业套餐限制。
