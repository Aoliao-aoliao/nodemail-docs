# 账号与安全

## 登录方式

草丛 Mail 支持本地账号和管理员已启用的 OAuth 登录。当前站点入口为 [https://to9.us/app/](https://to9.us/app/)，旧登录地址会自动转到新入口。

本地账号使用用户名和密码登录。注册、邮箱验证码、找回密码和绑定邮箱是否开放，以平台当时的后台设置为准。OAuth 按钮也只会显示已启用的提供方。

## 密码与会话

密码应只用于网页登录。邮件客户端请使用对应邮箱生成的应用专用密码。修改账号密码、完成密码找回、由管理员重置密码或重置 2FA 后，系统会撤销原有登录令牌；请在可信设备上重新登录。

忘记密码时，从登录页进入找回流程。账号必须已绑定可接收验证码的邮箱；若没有可用的绑定邮箱，请通过工单联系管理员核验身份。

找回邮箱不能在普通资料保存接口中直接改写，必须通过邮箱验证码绑定流程证明地址所有权。

## 两步验证

在账号安全设置中启用 TOTP 两步验证：

1. 用身份验证器扫描二维码或录入密钥。
2. 输入当前六位验证码完成确认。
3. 保存恢复信息，并退出后验证一次登录流程。

更换手机前先迁移身份验证器。若设备丢失且无法验证，只能联系管理员在核验身份后重置 2FA。

## OAuth 绑定

已登录用户可以绑定管理员开放的 OAuth 账号。解绑前应确认本地密码或另一种登录方式可用，避免失去账号访问权。

## 安全记录

安全记录包含登录来源、时间和关键账号操作。发现陌生记录时，依次修改密码、强制退出其他会话、撤销邮箱应用专用密码，并检查 OAuth 绑定。

## 凭据保护

- 不要在聊天、工单或截图中展示密码、TOTP 密钥、应用专用密码和 API 密钥。
- API 密钥只在创建时完整显示，应立即保存在密码管理器中。
- 公共设备使用完毕后退出账号，不要让浏览器保存凭据。
