# 个人设置

个人设置页面用于管理账号资料、邮箱偏好和安全记录。

## 账号信息

账号页会显示你的 NodeLoc 信息、当前等级、配额使用情况和已创建的邮箱。

## 通知设置

你可以设置通知方式。开启浏览器通知后，新邮件到达时可以收到提醒。

## 签名与模板

签名可以自动附加到邮件正文末尾。模板适合保存常用回复内容，写信时快速调用。

## 联系人

联系人页面可以保存常用收件人，写邮件时更方便填写地址。

## 白名单

白名单内发件人的邮件会更容易直接进入收件箱。请只添加你信任的地址。

## 图床设置

开启图床后，写信时粘贴或插入的图片会生成外链，收件人无需登录也能查看。

## 登录历史

安全页会显示当前登录和历史登录记录，包括浏览器、系统、IP 和时间。发现异常登录时，请及时联系管理员。

## 临时发信申请记录

安全页也会显示你的临时发信申请记录，包括申请状态、申请时间和有效期。

## 邮件客户端连接

网页邮箱不需要手动配置客户端服务器。

如果管理员开放 IMAP / POP3 / SMTP 客户端连接，默认建议统一使用：

```text
mail.to9.us
```

新增邮箱域名通常不需要单独添加客户端证书。只有当管理员明确让你使用 `mail.你的域名` 作为客户端服务器地址时，才需要确认该主机名已经配置有效证书。
