# 反馈与工单

## 提交问题

进入“管理 → 反馈与工单”创建工单。请至少提供：

- 出问题的页面或客户端。
- 操作步骤和预期结果。
- 页面完整错误文字。
- 发生时间与所在时区。
- 涉及的邮箱地址、邮件主题或订单号。

不要提交登录密码、应用专用密码、API Key、支付密钥、OAuth Secret 或完整私钥。邮件内容包含隐私时，只提供定位所需的最少信息。

## 沟通与状态

用户可以查看自己的工单、进入详情、回复、关闭和重新打开。管理员可统一筛选、回复、调整状态或删除无效工单。

## 常见问题分类

- 注册、登录、找回密码或两步验证。
- 邮箱创建、配额、共享和转让。
- 收不到邮件、邮件进入隔离区或附件异常。
- 发信审批、退信、抑制名单和投递失败。
- 企业域名验证、成员权限和企业邮箱。
- 套餐、订单、钱包充值和兑换码。
- API 密钥、客户端连接和通知绑定。

## 加快排查

网页问题可附浏览器名称、版本和截图；客户端问题应注明协议、端口和 TLS 模式；投递问题应提供发送时间、发件地址、收件域名与退信文字。管理员可结合审计日志和邮件流日志定位。
