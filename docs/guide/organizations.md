# 企业邮局

## 组织与角色

企业邮局把域名、成员、邮箱、套餐和品牌集中到一个组织中。

| 角色 | 主要权限 |
| --- | --- |
| 所有者 | 管理组织、订阅、成员和关键设置，可转移所有权 |
| 管理员 | 管理成员、域名和企业邮箱，权限受组织策略限制 |
| 成员 | 使用获分配的企业邮箱和组织资源 |

移除成员前应先处理其邮箱、共享关系和仍在进行的业务。所有权转移是关键操作，接收人应先加入组织并确认账号可用。

## 添加自有域名

1. 在组织域名页添加域名。
2. 按页面给出的值配置域名所有权验证记录。
3. 配置 MX、SPF、DKIM 和 DMARC。
4. 等待 DNS 生效后重新检查。
5. 验证完成后创建企业邮箱。

页面显示的记录值以当前组织配置为准，不要照抄其他域名的 DKIM 公钥或验证值。

## 企业邮箱

组织管理员可以创建、停用和管理企业邮箱。可创建数量和存储空间受当前企业套餐限制。停用邮箱前，应先导出或转交仍需保留的邮件。

## 品牌设置

组织可以配置显示名称、Logo 和主色，用于组织相关界面和通知。上传 Logo 后若没有立即变化，请刷新缓存并确认文件格式和大小符合页面要求。

## 发信通道

企业域名可使用平台直接投递或经批准的自定义中继。中继密码属于敏感凭据，只能在组织管理页保存，不应写入文档或提交到 Git。

## 套餐生命周期

组织订阅决定成员数、域名数、邮箱数和存储配额。取消通常在当前周期结束后生效；恢复订阅应在到期前完成。具体价格、周期和权益以套餐页实时显示为准。
