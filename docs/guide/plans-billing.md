# 套餐、钱包与订单

## 套餐

平台可提供免费、个人和企业套餐。每档套餐的邮箱数量、存储、发信额度、企业功能和计费周期由管理员配置，因此文档不固定写死价格。

升级前在套餐页核对：适用对象、计费周期、自动续费状态、当前配额和到期后的处理方式。

## 钱包

钱包以页面标明的币种显示余额。充值成功后会生成交易流水；余额支付则同时生成订单和扣款记录。不要仅凭浏览器跳转结果判断到账，应以钱包流水和订单状态为准。

## 订单状态

| 状态 | 说明 |
| --- | --- |
| 待支付 | 订单已创建，尚未收到有效支付结果 |
| 已支付 | 支付回调已验证，权益应开始生效 |
| 已取消/已关闭 | 订单不再接受支付 |
| 退款中/已退款 | 按平台支持情况处理，查看流水或联系管理员 |

支付页面关闭、网络中断或重复跳转时，先刷新订单状态。仍未更新再提交工单，并提供订单号；不要提供银行卡密码、支付密码或完整密钥。

## 兑换码

兑换码可能增加余额、套餐时长或特定权益，具体以兑换结果为准。每个兑换码有适用范围、有效期和使用次数限制。

## 订阅管理

取消订阅前查看权益终止时间。若系统支持恢复，可在当前周期结束前恢复。组织套餐由组织所有者或有权管理员管理，个人套餐由账号本人管理。
