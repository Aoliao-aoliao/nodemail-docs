# 套餐、钱包与订单

## 套餐

用户没有有效个人订阅时使用系统等级与默认配额形成的个人免费基础层。可购买的套餐记录分为个人 Pro 和企业 Business；每档套餐的邮箱数量、存储、发信额度、企业功能和计费周期由管理员配置，因此文档不固定写死价格。

升级前在套餐页核对：适用对象、计费周期、自动续费状态、当前配额和到期后的处理方式。

## 钱包

钱包以页面标明的币种显示余额。充值成功后会生成交易流水；余额支付则同时生成订单和扣款记录。不要仅凭浏览器跳转结果判断到账，应以钱包流水和订单状态为准。

## 订单状态

| 状态 | 说明 |
| --- | --- |
| 待支付 | 订单已创建，尚未收到有效支付结果 |
| 已支付 | 支付回调已验证，权益应开始生效 |
| 已取消/已关闭 | 订单不再接受支付 |
| 退款相关状态 | 当前用户端没有自动退款操作；以支付服务商、订单和钱包流水的实际记录为准并联系管理员 |

支付页面关闭、网络中断或重复跳转时，先刷新订单状态。仍未更新再提交工单，并提供订单号；不要提供银行卡密码、支付密码或完整密钥。

## 兑换码

当前兑换码用于免支付开通或延长个人 Pro 套餐，不直接增加能量余额。兑换码绑定指定套餐和时长，可设置有效期与总使用次数；同一用户对同一兑换码只能使用一次。

## 订阅管理

个人订阅可以在“订单与账单”取消自动续订，已支付权益保留到当前周期结束；到期前可恢复续订。企业订阅在组织页查看和购买，当前用户端没有企业订阅的取消或恢复按钮，需要由平台管理员按业务流程处理。
