# 快速开始

本页适合第一次使用草丛 Mail 的用户。网页应用统一位于 `/app`，旧版地址会自动跳转。

## 1. 注册或登录

打开 <https://to9.us/app/login>。页面可能提供以下方式，实际可用项由管理员配置：

- 本地账号：输入用户名和密码。
- NodeLoc OAuth：跳转到 NodeLoc 授权后返回草丛 Mail。
- 邮箱注册：在 <https://to9.us/app/register> 填写用户名和密码。未强制邮件认证时找回邮箱可以留空，之后再到账号设置中绑定；管理员启用邮件认证后，找回邮箱为必填，并需输入收到的验证码后才会创建账号。注册入口是否开放以页面显示为准。

如果忘记本地密码，可在 <https://to9.us/app/forgot-password> 使用已验证的绑定邮箱接收重置码。未绑定邮箱的账号需要联系管理员重置。

## 2. 完成首次引导

真正的新账号登录后会进入首次引导页。已经创建过邮箱或已经完成引导的账号再次登录时会直接进入邮箱；管理员账号直接进入后台，不需要重复绑定或创建个人邮箱。个人邮箱的数量、存储和每日发信量由系统配额等级、个人套餐及管理员覆盖值共同决定；企业邮箱的数量、存储和全组织共享每日发信量由组织订阅管理。

## 3. 创建邮箱

进入“管理 → 邮箱管理”，填写邮箱前缀并选择可注册域名。系统会实时检查地址是否可用。以下类型的前缀通常保留给平台管理：

```text
admin
root
postmaster
security
abuse
```

创建后可设置显示名称、排序、外部转发、自动回复和应用专用密码。邮箱级转发可以填写有效外部邮箱；收信规则里的转发只允许本人已验证的找回邮箱。两者都会使用正常出站路由并计入相应的个人或组织每日发信额度；个人邮箱超出免费额度时可能消耗能量。设置后应发送专用测试邮件。平台也可能关闭某个域名的公开注册，或设置最低用户等级。

## 4. 收信与发信

点击左上角邮箱选择器，在单个邮箱和“全部邮箱”之间切换。点击“写邮件”选择发件地址，填写收件人、主题、正文和附件。

若管理员对公共域名启用了发信审批策略，页面会提示当前不能发信；此时可在写信页提交发信权限申请，管理员批准后才能使用相应域名发信。是否需要审批以页面当前状态为准。

## 5. 完成安全设置

建议首次登录后立即完成：

1. 本地账号绑定并验证找回邮箱；第三方登录账号通过原登录平台维护恢复方式。
2. 开启 TOTP 两步验证，并在启用时安全备份 TOTP 密钥；当前不提供一次性恢复码。
3. 检查登录历史和活动会话。
4. 需要第三方客户端时，为每个邮箱单独创建应用专用密码，不要使用网页登录密码。

具体步骤见[账号与安全](/guide/account-security)。

若使用 NodeLoc，请同时阅读 [NodeLoc 身份、等级与本站配额](/guide/nodeloc-identity)，不要把 NodeLoc 的 `TL` 会员等级与本站的 `L` 配额档位混为一谈。

## 6. 认识主要页面

| 页面 | 用途 |
| --- | --- |
| 邮件 | 收件箱、文件夹、搜索、会话阅读和写信 |
| 数据面板 | 邮件数量、趋势与常用联系人 |
| 邮箱管理 | 地址、显示名、排序、自动回复和客户端密码 |
| 联系人 | 通讯录与自动发现的往来地址 |
| 规则 | 自动处理来信 |
| 被拦截邮件 | 安全预览、放行或永久删除高风险隔离邮件 |
| 共享 | 直接授权其他用户只读查看指定范围 |
| 清理中心 | 对本人个人邮箱执行延迟删除、取消清理、永久保留与彻底清空；企业邮箱不在此范围 |
| 企业邮局 | 组织、域名、成员、企业邮箱和品牌 |
| 我的套餐 | 套餐、订阅、兑换码与配额 |
| 订单与账单 | 钱包、充值、订单和交易记录 |
| 通知中心 | 系统公告和个人事件通知 |
| 开发者 | API 密钥与接口说明 |
