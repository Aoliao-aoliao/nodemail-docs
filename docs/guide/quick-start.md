# 快速开始

本页适合第一次使用草丛 Mail 的用户。网页应用统一位于 `/app`，旧版地址会自动跳转。

## 1. 注册或登录

打开 <https://to9.us/app/login>。页面可能提供以下方式，实际可用项由管理员配置：

- 本地账号：输入用户名和密码。
- NodeLoc OAuth：跳转到 NodeLoc 授权后返回草丛 Mail。
- 邮箱注册：在 <https://to9.us/app/register> 填写用户名、找回邮箱和密码，再输入邮件验证码。正式系统当前开放注册，找回邮箱不能为空。

如果忘记本地密码，可在 <https://to9.us/app/forgot-password> 使用已验证的绑定邮箱接收重置码。未绑定邮箱的账号需要联系管理员重置。

## 2. 完成首次引导

新账号登录后可能进入首次引导页。按提示确认账号信息、可用域名和当前套餐配额，再创建第一个邮箱。能创建多少邮箱、可用存储和每日发信量由用户等级、个人套餐、企业套餐及管理员覆盖值共同决定。

## 3. 创建邮箱

进入“管理 → 邮箱管理”，填写邮箱前缀并选择可注册域名。系统会实时检查地址是否可用。以下类型的前缀通常保留给平台管理：

```text
admin
root
postmaster
security
abuse
```

创建后可设置显示名称、排序、转发、自动回复和应用专用密码。平台也可能关闭某个域名的公开注册，或设置最低用户等级。

## 4. 收信与发信

点击左上角邮箱选择器，在单个邮箱和“全部邮箱”之间切换。点击“写邮件”选择发件地址，填写收件人、主题、正文和附件。

正式环境当前对公共域名启用了发信审批策略。若页面提示不能发信，可在写信页提交发信权限申请；管理员批准后才能使用相应域名发信。

## 5. 完成安全设置

建议首次登录后立即完成：

1. 绑定并验证找回邮箱。
2. 开启 TOTP 两步验证并保存恢复信息。
3. 检查登录历史和活动会话。
4. 需要第三方客户端时，为每个邮箱单独创建应用专用密码，不要使用网页登录密码。

具体步骤见[账号与安全](/guide/account-security)。

## 6. 认识主要页面

| 页面 | 用途 |
| --- | --- |
| 邮件 | 收件箱、文件夹、搜索、会话阅读和写信 |
| 数据面板 | 邮件数量、趋势与常用联系人 |
| 邮箱管理 | 地址、显示名、转发、自动回复和客户端密码 |
| 联系人 | 通讯录及联系人访问控制 |
| 规则 | 自动处理来信 |
| 共享 | 邀请其他用户协作处理邮箱 |
| 清理中心 | 延迟删除、取消清理、永久保留与彻底清空 |
| 企业邮局 | 组织、域名、成员、企业邮箱和品牌 |
| 我的套餐 | 套餐、订阅、兑换码与配额 |
| 订单与账单 | 钱包、充值、订单和交易记录 |
| 通知中心 | 系统公告和个人事件通知 |
| 开发者 | API 密钥与接口说明 |
