# 域名管理

域名管理用于添加收信域名、生成 DKIM、检查 DNS 状态。

## 添加域名

添加域名后，系统会给出推荐 DNS 记录。

建议先添加：

```text
example.com
```

然后配置：

```text
MX -> mail.example.com
SPF
DKIM
DMARC
```

## DNS 健康检查

DNS 健康检查会验证：

- MX 是否正确
- SPF 是否存在
- DKIM 是否匹配
- DMARC 是否存在

DNS 解析有缓存，修改后可能需要等待几分钟到数小时。

## 禁止发信

当域名 PTR 未稳定、信誉未恢复或被黑名单影响时，可以临时禁止该域名发信。

用户需要申请临时发信权限，管理员审批后才可发送。
