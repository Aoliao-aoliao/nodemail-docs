# 用户与邮箱管理

## 用户

用户列表支持查看账号状态、等级、配额、绑定信息和近期活动。管理员可以启用或禁用账号、调整授权范围、强制退出会话，以及在核验身份后重置两步验证。

禁用账号会阻止其继续使用服务，但不等同于立即删除数据。删除前应确认邮箱归属、组织角色、订单和工单等关联关系。

## 邮箱

邮箱管理页显示地址、域名、所有者、状态、容量和发信资格。常见操作包括：

- 创建、停用或恢复邮箱。
- 调整显示顺序和容量限制。
- 查看共享关系、应用专用密码状态与活动记录。
- 转让邮箱或安排延迟清理。
- 对已进入清理流程的邮箱永久保留或彻底删除。

邮箱转让后，原用户不应继续持有访问权限；检查共享成员和应用专用密码并按需撤销。

## 邮件数据

管理员处理邮件问题时应遵守最小访问原则。优先根据邮件 ID、时间、投递状态和日志排查，只有在确有需要时才查看正文或附件。

## 配额

用户可用邮箱数、存储和发信额度可能同时受到账号等级、个人套餐和组织套餐影响。调整后若界面未变化，检查权益生效时间和缓存，再确认数据库中的实际配额来源。
