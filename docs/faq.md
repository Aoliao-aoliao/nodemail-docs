# 常见问题

## 谁可以使用 NodeMail？

NodeMail 当前主要面向 NodeLoc 黄金会员及以上用户开放。实际开放范围以页面提示和管理员审核为准。

## 怎么登录？

访问 `https://to9.us/login`，使用 NodeLoc 第三方登录完成授权。

## 为什么我不能发信？

如果写信页面提示当前域名暂时禁止发信，说明发信功能正在受限。你可以在写信页面申请临时发信权限，等待管理员审核。

## 为什么申请临时发信要写原因？

这是为了保护邮箱服务的整体信誉。请简单说明用途，例如正常沟通、账号验证、联系客户或测试收信。

## 为什么不要大量发信？

NodeMail 不是群发工具。大量重复内容、短时间高频发送或不正常内容可能影响整个服务的发信体验。

## 发件方 DKIM 未通过是什么意思？

这表示当前收到的邮件在发件方 DKIM 签名验证上没有通过。它通常是发件方域名或邮件链路的问题，不代表你的 NodeMail 邮箱 DKIM 配置错误。判断邮件是否可信时，还需要同时参考 SPF、DMARC、发件人身份、正文内容和附件风险。

## 管理员可以创建 admin 邮箱吗？

可以。普通用户不能创建系统保留前缀，管理员可以创建。

## 收不到邮件怎么办？

先检查垃圾邮件、已删除、被拦截邮件和收信规则。如果仍然找不到，可以提交工单并说明收件地址、发件方和大概发送时间。

## 附件打不开怎么办？

可以先重新下载一次附件。如果仍然异常，请提交工单，并写清楚邮件主题、附件名称和发生时间。

## 新增邮箱域名后需要单独加证书吗？

只使用网页邮箱时不需要。网页访问使用 `https://to9.us/login`。

如果使用 IMAP / POP3 / SMTP 客户端，并且服务器地址统一填写 `mail.to9.us`，证书只需要覆盖 `mail.to9.us`。只有计划让用户填写 `mail.新域名` 作为客户端服务器地址时，才需要为这个新主机名配置证书。
